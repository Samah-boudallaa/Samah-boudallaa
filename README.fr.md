## Architectures

<sub>Chaque schéma est accompagné d'une version texte, pour les lecteurs d'écran et les connexions lentes.</sub>

### Smart Data Pipeline

<div align="center">
<img src="./assets/arch-smart-pipeline.svg" alt="Architecture de Smart Data Pipeline : données IoT simulées, Kafka, moteur adaptatif Pandas et Spark, détection d'anomalies Isolation Forest et métriques Prometheus, résultats de détection et dashboards Grafana." width="100%"/>
</div>

<sub><b>Version texte :</b> mesures IoT simulées → Apache Kafka (KRaft) → moteur adaptatif (Pandas / Spark) → Isolation Forest (détection d'anomalies) → résultats de détection ; le moteur expose aussi des métriques Prometheus → supervision Grafana.</sub>

### NexaDecide

<div align="center">
<img src="./assets/arch-nexadecide.svg" alt="Architecture de NexaDecide : SQL Server, pipeline ETL, cache DuckDB et Parquet, FastAPI, puis prévision XGBoost, assistant RAG et interface Streamlit, avec une instance de test Odoo CRM reliée à l'API." width="100%"/>
</div>

<sub><b>Version texte :</b> SQL Server → pipeline ETL → cache analytique DuckDB / Parquet → API FastAPI → (prévision du chiffre d'affaires XGBoost · RAG avec LangChain et Mistral AI · interface Streamlit). L'API et une instance de test Odoo CRM échangent des données dans les deux sens via XML-RPC.</sub>

### GraphGen

<div align="center">
<img src="./assets/arch-graphgen.svg" alt="Architecture de GraphGen : fichiers CSV et Excel, Flask et Pandas, analyse des données, graphiques Plotly ; avec Docker, pytest et ruff, et GitHub Actions pour la qualité et la livraison." width="100%"/>
</div>

<sub><b>Version texte :</b> fichiers CSV / Excel → Flask + Pandas → analyse des données → visualisations Plotly. Branche qualité : Flask + Pandas → pytest et ruff → GitHub Actions ; le tout empaqueté dans une image Docker non-root.</sub>
